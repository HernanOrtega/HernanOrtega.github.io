# Calculadora web sencilla funcional hecha con HTML, CSS y Javascript.
## PASOS PARA EJECUTARLA
- Descarga el archivo index.html o ingresa al siguiente link: https://hernanortega.github.io/

## FUNCIONES IMPLEMENTADAS
- Se puede realizar operaciones de suma, resta, multiplicación y división (ésta última verificando el uso de ceros).
- También es posible observar un historial de las últimas 5 operaciones realizadas.
